# ١) دليل أسئلة الذكاء (IQ) — ملف واحد ملوّن

ملف HTML **واحد مستقل تمامًا** يجمع أنواع أسئلة الذكاء المشروحة في قناة
[هنتعلم أون لاين مع إيمان السيد](https://youtube.com/@emanelsayed.online)
(أشكال وصور وأرقام وحروف ومنطق)، مع **طريقة حل كل نوع خطوة بخطوة**
و**رسمة لكل شكل بجانب شرحه**.

📄 **الملف الجاهز:** [`iq-guide.html`](iq-guide.html) — افتحه بأي متصفح (يعمل بدون إنترنت).
📝 **نسخة Word:** [`iq-guide.docx`](iq-guide.docx) — الأسئلة الأساسية (١٠٩) بالصور وخطوات الحل، قابلة للتعديل والطباعة.

## ما بداخله

| القسم | المحتوى |
|---|---|
| ١٩ محورًا | ٨٣٦ سؤالًا محلولًا (١٠٩ أساسية مشروحة + ٧٢٧ في بنوك تدريب مولّدة): المتتابعات، المكمِّل، المصفوفات، المطابق/المُدار، المرايا، طي الورق، المكعبات، التصور المكاني، تركيب X‑Y‑Z، الدمج والطرح، عدّ الأشكال، الشكل الشاذ، المتسلسلات العددية، متتاليات الحروف، الأعداد داخل الأشكال، الميزان، العلاقات اللفظية، تعبيرات الوجه، الاستدلال المنطقي |
| لكل محور | فكرة السؤال + خطوات الحل + الأخطاء الشائعة + الفيديوهات المرجعية |
| لكل سؤال | الشكل مرسومًا (SVG ملوّن) + الاختيارات + الإجابة + خطوات الوصول إليها + تنبيه على الفخ |
| بنك تدريب لكل محور | قسم «🎯 بنك تدريب إضافي» مطويّ في نهاية كل محور: عشرات الأسئلة المولّدة آليًا بنفس النمط، كل سؤال برسمته وخطوات حله |
| ملاحق | جدول الأنماط السريع، ١٠ نصائح امتحان، خطة مذاكرة ٧ أيام، اختبار ذاتي ١٠ أسئلة، ٣٠ مصدرًا من القناة |
| الأشكال | ٢١٢٠ شكلًا مرسومًا بـ SVG داخل الملف (لا صور خارجية ولا إنترنت) |

مزايا الملف: زر **إظهار/إخفاء الإجابات**، زر **فتح بنوك التدريب** دفعة واحدة، قائمة **انتقال سريع** لأي محور، فهرس، وتنسيق **طباعة** جاهز (زر الطباعة ⇐ يمكن حفظه PDF من المتصفح؛ تُفتح بنوك التدريب تلقائيًا قبل الطباعة).

## إعادة البناء

```bash
python3 src/selfcheck.py   # فحص بنك الأسئلة (سلامة البيانات + منطق المكعبات والمجسمات)
python3 src/build.py       # يُنتج iq-guide.html
python3 src/build_docx.py  # (اختياري) يُنتج iq-guide.docx — يحتاج python-docx و pymupdf
```

لا يحتاج أي حزم خارجية؛ الخطوط مضمّنة داخل الملف (base64) ولا توجد أي موارد عبر الإنترنت.

| الملف | الدور |

| `assets/fonts/` | خطوط Cairo (woff2) تُضمَّن داخل الملف |

# ٢) بنك أسئلة التربوي — ملف واحد ملوّن

📄 **الملف الجاهز:** [`tarbawy-guide.html`](tarbawy-guide.html) — افتحه بأي متصفح (يعمل بدون إنترنت).

**٧٦٩٢ سؤالًا** في التربوي بالإجابة النموذجية وشرح سبب الإجابة، موزعة على ١١ محورًا
(علم النفس التربوي، الأهداف، المناهج، طرق التدريس، القياس والتقويم، مسائل القياس والإحصاء،
تكنولوجيا التعليم، الإدارة الصفية، التشريعات وأخلاقيات المهنة، البحث والتنمية المهنية، التربية الخاصة)
و١٤٣ موضوعًا فرعيًا.

| القسم | المحتوى |
|---|---|
| 🗂️ بنك الأسئلة | بحث فوري + تصفية بالمحور والموضوع والمصدر + إظهار/إخفاء كل الإجابات + ترتيب عشوائي + ترقيم صفحات |
| 📝 وضع الامتحان | اختبار ذاتي (١٠ / ٢٠ / ٣٠ / ٥٠ / ١٠٠ سؤالًا) من أي محور، بتصحيح فوري ودرجة وشرح لكل سؤال |
| ⚡ المراجعة السريعة | ٥٠٧ مفاهيم في ٨٣ مجموعة (المصطلح + تعريفه + صاحبه + مثال تطبيقي + ملاحظات الامتحان) |
| 🖨️ الطباعة | تنسيق طباعة يُظهر الإجابات والشروح (Ctrl+P ⇐ حفظ PDF) |

**تركيب المحتوى:** ٩٧ سؤالًا من الأسئلة المتداولة في امتحانات المسابقات + ٣٢ موقفًا تدريسيًا
بالإجابة الأفضل مهنيًا + باقي الأسئلة مشتقة منهجيًا من قاعدة المفاهيم (تعريف ⇄ مصطلح، «يُعد من»/«ليس من»،
صاحب النظرية، الترتيب، المواقف التطبيقية) + ٤٢٩٠ مسألة حسابية في القياس والإحصاء بحلول خطوة بخطوة
(معامل السهولة والصعوبة والتمييز، جدول المواصفات، النزعة المركزية والتشتت، الدرجة المعيارية والتائية،
سبيرمان–براون، المتوسط المرجّح، النسب المئوية).

## إعادة البناء

```bash
python3 src/check_tarbawy.py   # فحص البنك: تكرار، مفاتيح، بدائل ملتبسة، تحقق مستقل من المسائل الحسابية
python3 src/build_tarbawy.py   # يُنتج tarbawy-guide.html
```

### بنية المصدر

| الملف | الدور |
|---|---|
| `src/tarbawy/kb_core.py` | قاعدة المفاهيم (١): نظريات التعلم، الأعلام، بلوم، النمو، الدافعية، الذكاءات، المناهج، طرق التدريس |
| `src/tarbawy/kb_eval.py` | قاعدة المفاهيم (٢): القياس والتقويم والإحصاء، الوسائل، الإدارة الصفية، التشريعات، الأخلاقيات، البحث والجودة |
| `src/tarbawy/kb_extra.py` | قاعدة المفاهيم (٣): فيجوتسكي، باندورا، انتقال الأثر، نماذج التدريس الحديثة، الدمج، حقوق المتعلم |
| `src/tarbawy/kb_more.py` | قاعدة المفاهيم (٤): مهارات التفكير، المراحل العمرية، الإشراف، الإرشاد، القيادة، التعلم عن بُعد |
| `src/tarbawy/gen.py` | مولّدات الأسئلة (٧ قوالب مفاهيمية + ١٥ أسرة حسابية) مع توزيع الإجابة على الحروف ومنع البدائل الملتبسة |
| `src/tarbawy/curated.py` | الأسئلة المتداولة من امتحانات المسابقات + بنك المواقف التدريسية، بإجاباتها وتعليلها |
| `src/build_tarbawy.py` | يولّد `tarbawy-guide.html` (CSS + JS + البيانات داخل الملف) |

# ٣) مسابقة تعيين معلم لغة عربية — الأزهر الشريف

📄 **الملف الجاهز:** [`azhar-arabic-guide.html`](azhar-arabic-guide.html) — افتحه بأي متصفح (يعمل بدون إنترنت).

**١٢١٧١ سؤالًا** بالإجابة النموذجية وسبب الإجابة، موزعة على **٧ أقسام** و**٢٣٦ موضوعًا**،
مع **تمييز بصري للأسئلة الأشهر والأكثر تكرارًا** في المسابقة.

## تمييز الأسئلة المتكررة (أهم مزايا الملف)

| العلامة | المعنى | العدد |
|---|---|---|
| ⭐ **الأكثر تكرارًا** | سؤال كلاسيكي متداول في نماذج المسابقة — بطاقته بخلفية ذهبية وإطار مميز | ٩٣١ |
| 🔁 **متكرر** | من الموضوعات والأنماط التي يتكرر ورودها في الامتحان | ٤٦٣٦ |
| (بلا علامة) | سؤال تدريبي إضافي لاستكمال التغطية | ٦٦٠٤ |

يوجد تبويب مستقل **«🔥 الأشهر والأكثر تكرارًا»** يجمع هذه الأسئلة وحدها مرتبةً حسب القسم،
وزرّ **«⭐ المتكرر فقط»** داخل بنك الأسئلة، ووضع امتحان خاص **«من المتكرر فقط»**.

## توزيع الأقسام

| القسم | عدد الأسئلة | أهم ما فيه |
|---|---|---|
| التخصص — لغة عربية | ٢٢٧٢ | النحو والإعراب، الصرف والميزان، البلاغة، الأدب والعصور، الإملاء، العروض، النصوص الشرعية والتجويد |
| التربوي | ٧٦٩٢ | المحاور الـ١١ كاملة (مشتركة مع بنك التربوي) |
| الكفايات السلوكية | ١٦٦ | المواقف الوظيفية، إدارة الخلاف، أخلاقيات المهنة، إدارة الوقت |
| الحاسب الآلي | ٥٢٤ | المكونات، الذاكرة، أوفيس، الإنترنت والأمان، وحدات القياس والتحويلات |
| المعلومات العامة | ٣٣٩ | الأزهر وتاريخه، مصر، التاريخ الإسلامي، الجغرافيا، العلوم، المنظمات الدولية |
| اللغة الإنجليزية | ٢٩٢ | القواعد، الأزمنة، تصريف الأفعال الشاذة، حروف الجر، المقارنة، الجمع، المصطلحات التربوية |
| الذكاء IQ | ٨٨٦ | المتتابعات العددية والحرفية، العلاقات، الشاذ، المنطق، النسب، الأعمار، السرعة والمسافة |

## الواجهة

| التبويب | المحتوى |
|---|---|
| 🔥 الأشهر والأكثر تكرارًا | الأسئلة المميزة وحدها مجمّعة بالقسم، ببحث خاص وزر إظهار الكل |
| 🗂️ بنك الأسئلة | تصفية بالقسم والموضوع + بحث فوري + «المتكرر فقط» + ترتيب عشوائي + ترقيم صفحات (١٠/٢٥/٥٠/١٠٠) |
| 📝 امتحان محاكٍ | ثلاثة أوضاع: محاكاة المسابقة بنِسَب الأقسام الحقيقية، أو من المتكرر فقط، أو من قسم واحد — بتصحيح فوري ودرجة لكل قسم |
| ⚡ المراجعة السريعة | ١٢٨ مجموعة مفاهيم (المصطلح + تعريفه + صاحبه + مثال) بالتصفية والبحث |
| ℹ️ عن الملف | جدول التوزيع وخطة المذاكرة |

## إعادة البناء

```bash
python3 src/check_azhar.py   # فحص البنك قبل النشر
python3 src/build_azhar.py   # يُنتج azhar-arabic-guide.html
```

**المدقق `check_azhar.py`** يفحص: سلامة البنية (٤ بدائل متمايزة لكل سؤال ومفتاح صالح وتعليل غير فارغ)،
البدائل الملتبسة (مع استثناء التضاد بالنفي وأسئلة الإملاء التي يكون التمايز فيها بالهمزة مقصودًا)،
التناقض (نفس المتن بمفتاحين، وخيار صحيح وخاطئ معًا، والاشتراك اللفظي بين الموضوعات)،
توازن توزيع المفاتيح، و**إعادة حساب مستقلة لكل مفتاح رقمي** (٤٨٠ سؤالًا: تحويلات وحدات التخزين،
النسب المئوية، السرعة والمسافة، المتتابعات الحسابية والهندسية). الحالة الحالية: **صفر أخطاء وصفر تنبيهات**.
