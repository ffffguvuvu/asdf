# دليل أسئلة الذكاء (IQ) — ملف واحد ملوّن

ملف HTML **واحد مستقل تمامًا** يجمع أنواع أسئلة الذكاء المشروحة في قناة
[هنتعلم أون لاين مع إيمان السيد](https://youtube.com/@emanelsayed.online)
(أشكال وصور وأرقام وحروف ومنطق)، مع **طريقة حل كل نوع خطوة بخطوة**
و**رسمة لكل شكل بجانب شرحه**.

📄 **الملف الجاهز:** [`iq-guide.html`](iq-guide.html) — افتحه بأي متصفح (يعمل بدون إنترنت).

## ما بداخله

| القسم | المحتوى |
|---|---|
| ١٩ محورًا | ١٠٩ أسئلة محلولة: المتتابعات، المكمِّل، المصفوفات، المطابق/المُدار، المرايا، طي الورق، المكعبات، التصور المكاني، تركيب X‑Y‑Z، الدمج والطرح، عدّ الأشكال، الشكل الشاذ، المتسلسلات العددية، متتاليات الحروف، الأعداد داخل الأشكال، الميزان، العلاقات اللفظية، تعبيرات الوجه، الاستدلال المنطقي |
| لكل محور | فكرة السؤال + خطوات الحل + الأخطاء الشائعة + الفيديوهات المرجعية |
| لكل سؤال | الشكل مرسومًا (SVG ملوّن) + الاختيارات + الإجابة + خطوات الوصول إليها + تنبيه على الفخ |
| ملاحق | جدول الأنماط السريع، ١٠ نصائح امتحان، خطة مذاكرة ٧ أيام، اختبار ذاتي ١٠ أسئلة، ٣٠ مصدرًا من القناة |

مزايا الملف: زر **إظهار/إخفاء الإجابات**، قائمة **انتقال سريع** لأي محور، فهرس، وتنسيق **طباعة** جاهز (زر الطباعة ⇐ يمكن حفظه PDF من المتصفح).

## إعادة البناء

```bash
python3 src/selfcheck.py   # فحص بنك الأسئلة (سلامة البيانات + منطق المكعبات والمجسمات)
python3 src/build.py       # يُنتج iq-guide.html
```

لا يحتاج أي حزم خارجية؛ الخطوط مضمّنة داخل الملف (base64) ولا توجد أي موارد عبر الإنترنت.

### بنية المصدر

| الملف | الدور |
|---|---|
| `src/svgkit.py` | أدوات رسم SVG (أشكال، مصفوفات، مكعبات، شبكات مفرودة، مجسمات، ميزان، وجوه…) |
| `src/model.py` | نماذج `Q` و`Chapter` + `reorder`/`balance_answers` لتوزيع الإجابات على الحروف |
| `src/content_a.py` | المحاور ١–٦ |
| `src/content_b.py` | المحاور ٧–١٢ |
| `src/content_c.py` | المحاور ١٣–١٩ |
| `src/extras.py` | الجدول السريع، النصائح، الخطة، الاختبار الذاتي، المصادر |
| `src/build.py` | يولّد `iq-guide.html` (CSS + JS + الخطوط المضمّنة) |
| `src/selfcheck.py` | فحص ذاتي قبل البناء |
| `src/preview_figs.py` | أداة تطوير: تُخرج ورقة معاينة SVG لكل محور للتأكد من صحة الرسومات |
| `assets/fonts/` | خطوط Cairo (woff2) تُضمَّن داخل الملف |
