## 📌 نظرة عامة
تطبيق ومنصة ويب تفاعلية متكاملة وشاملة تم تصميمها لمحاكاة لجان واختبارات **الجهاز المركزي للتنظيم والإدارة** ومسابقات **وزارة التربية والتعليم** و**الأزهر الشريف** و**وزارة الأوقاف**. 

تم بناء المنصة كصفحة واحدة تفاعلية سريعة (Single Page Application) تعمل بكفاءة وبدون أي مكتبات خارجية ثقيلة، مع دعم كامل للاتجاه من اليمين لليسار (RTL) والتوافق مع شاشات الهواتف والأجهزة اللوحية والحواسيب المكتبية.

## 🌟 أهم المحاور والميزات

### 1. ⏱️ محاكي الاختبارات الموقوت (Real-time Mock Simulator)
- **محاكاة دقيقة** لشاشات قاعات امتحانات مركز تقييم القدرات والمسابقات الحكومية.
- **توقيت تنازلي ذكي** (20 دقيقة، 15 دقيقة، 30 دقيقة، أو تدريب حر بدون وقت).
- **لوحة تنقل بين الأسئلة (Question Palette)** لمعرفة الأسئلة المجاب عنها، المتبقية، أو المميزة بعلامة.
- **تمييز الأسئلة للمراجعة (Flag for review)** للرجوع إليها قبل إنهاء الاختبار.
- **مؤثرات صوتية تفاعلية** عبر تقنية Web Audio API (بدون ملفات خارجية) مع خيار الكتم/التشغيل.
- **لوحة نتائج وتحليل فوري:** تعرض النسبة المئوية العامة، تقييماً تشخيصياً (ممتاز / مبشر / يحتاج تدريب)، وتحليلاً تفصيلياً لنسبة الإتقان في كل محور على حدة.

### 2. 🎯 اختبار بنك نقاط الضعف الذكي (Weak Points Trainer)
- يسجل النظام تلقائياً وبشكل فوري أي سؤال يجيب عليه المتدرب بشكل غير صحيح في أي اختبار.
- يتيح للمتدرب الدخول في جلسة تدريب مخصصة تركز فقط على أخطائه السابقة مع بيان أسباب الخطأ والقاعدة النحوية أو العلمية الصحيحة.
- إمكانية تعليم السؤال بـ "تم الإتقان" بمجرد استيعابه ليتم حذفه تلقائياً من قائمة نقاط الضعف.

### 3. 🗺️ خريطة المذاكرة الذكية (Smart Study Roadmap)
- خطط دراسية مجدولة بحسب الوقت المتاح قبل موعد الامتحان:
  - **خطة الأسبوع المكثفة (7 أيام):** مقسمة يوماً بيوم لتغطية كل محور مع حل الاختبارات.
  - **خطة الأسبوعين المتوازنة (14 يوماً):** دراسة متأنية وموسعة لجميع الشروحات والقواعد.
  - **خطة المراجعة السريعة (3 أيام):** تلخيص سريع لأهم الأسئلة المتكررة.
- شريط تقدم تفاعلي يحسب نسبة الإنجاز والمهام المتبقية.

### 4. 📚 بنك الأسئلة الشامل والمحلول
- بنك أسئلة غني يغطي المحاور الستة الأساسية:
  1. **الكفايات والجدارات السلوكية:** سيناريوهات النزاهة والانضباط وحل المشكلات وضغط العمل.
  2. **الذكاء والتفكير المنطقي (IQ):** متتاليات الأعداد الفردية والمركبة، تدوير الأشكال، طي المكعبات، والنرد القياسي مع رسوم توضيحية SVG.
  3. **اللغة العربية:** همزات الوصل والقطع، الهمزة المتوسطة والمتطرفة، إعراب كان وأخواتها والأسماء الخمسة، وعلامات الترقيم.
  4. **اللغة الإنجليزية:** القواعد الأساسية، حروف الجر، وحصيلة المفردات المهنية.
  5. **الحاسب الآلي وتكنولوجيا المعلومات:** اختصارات Windows وOffice (F12, Windows+D, Ctrl+Shift+Esc)، دوال Excel (COUNT vs COUNTA)، والأمن السيبراني (التصيد الاحتيالي Phishing).
  6. **المعلومات العامة والمشروعات القومية والدستور:** مبادرة حياة كريمة، محطة الضبعة النووية، العاصمة الإدارية، قانون الخدمة المدنية رقم 81 لسنة 2016، ونسب الإنفاق الدستوري.
  7. **الكفايات التربوية:** نظريات التعلم (بياجيه، فيجوتسكي)، التقويم البنائي والتكويني، استراتيجيات التعلم النشط والعصف الذهني.
  8. **الأزهر الشريف والأوقاف والقرآن:** أحكام التجويد، كتاب (الحق المبين في الرد على من تلاعب بالدين)، ومفهوم الوطن في الشريعة.
- محرك بحث فوري لتصفية الأسئلة بالكلمات المفتاحية والمحاور.

### 5. 📖 مكتبة الشروحات ورقة المراجعة السريعة (Printable PDF)
- بطاقات مراجعة مركزة تحوي القواعد الذهبية لكل قسم.
- زر مخصص لطباعة وتصدير ورقة المراجعة مباشرة إلى ملف **PDF** مهيأ للطباعة (A4 Print-ready).
