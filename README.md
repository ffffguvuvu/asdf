# asdf

## المرجع الشامل لأسئلة IQ (القدرات الذهنية)

`IQ-guide.html` — ملف عربي ملّون (RTL) يجمع أسئلة الـ IQ (الصور والأشكال والأعداد والحروف)
مع **طريقة الحل خطوة بخطوة** و**رسم توضيحي لكل شكل بجانب الشرح**، مستخلص من فيديوهات قناة
[«هنتعلم أون لاين مع إيمان السيد»](https://youtube.com/@emanelsayed.online)
وقائمة تشغيل [IQ - نسبة الذكاء](https://www.youtube.com/playlist?list=PLO9L9sHOfqhPGsDyK_JAvNnkP0Ua8o_6Q).

### محتويات الملف (11 بابًا، 88 سؤالًا)
المتتاليات العددية · متتاليات الحروف · المصفوفات الرقمية · الشكل المكمل · المكعبات وطيّها ·
التدوير والتصور المكاني (بيردو) · الأشكال المتطابقة والمماثلة · تركيب الأشكال X/Y/Z ·
المرايا وثني الورق · تعبيرات الوجه · أنماط إضافية (الشكل الشاذ، التناظر اللفظي، الاستنتاج، المواقف)
+ خطة مذاكرة 7 أيام ونصائح يوم الامتحان.

### بنية المشروع
```
IQ-guide.html        الملف النهائي (يُفتح في المتصفح، ويمكن طباعته إلى PDF)
tools/iq_svg.py      أدوات رسم الأشكال (SVG) Shared helpers
tools/content_a.py   محتوى الأبواب: الأعداد والحروف والمصفوفات
tools/content_b.py   محتوى الأبواب: الأشكال والمكعبات والتصور المكاني والمتطابقة
tools/content_c.py   محتوى الأبواب: التركيب والمرايا والوجوه والأنماط الإضافية
tools/build.py       يولّد IQ-guide.html من ملفات المحتوى
notes/               ملاحظات مجمّعة من تفريغات الفيديوهات (المصدر الخام)
```

### إعادة التوليد
```bash
python3 tools/build.py
```

> **تنبيه:** الرسوم داخل الملف **إعادة رسم توضيحية** مبنية على وصف الشرح في الفيديوهات
> (لا يمكن أخذ لقطات من الفيديو نفسه)، وهي مطابقة في الفكرة والخصائص للغرض التدريبي.
> المحتوى استرشادي ولا يُعد ضمانًا لتكرار الأسئلة في الامتحان.
