# منصة إجتـاز التعليمية — Egtaz Educational Platform

نسخة ويب تطابق [egtaz.online](https://egtaz.online/) — منصة تعليمية عربية (RTL) للتدريب على مسابقات التنظيم والإدارة والتربية والتعليم، بواجهة داكنة (slate + emerald) وخط Cairo.

## المحتوى

- **الرئيسية**: قسم تعريفي، تنويه هام، روابط واتساب / تليجرام / فيسبوك، شريط تنزيل التطبيق.
- **اختبارات مختارة لك**: كاروسيل تلقائي قابل للسحب باللمس/الماوس مع عداد الشرائح — يشغّل محرك اختبار تفاعلي (مؤقت، مراجعة الإجابات، نتيجة).
- **الأقسام التدريبية**: 12 قسمًا (لغة عربية الأزهر، القرآن الكريم، الخارجية، طبيب بيطري، …).
- **لوحة تقدمك**: أداء المحاور، سجل المحاولات، اختبار نقاط الضعف، البحث الشامل.
- **خريطة المذاكرة الذكية**: إنشاء خطة حسب التخصص وعدد الأيام (تُحفظ محليًا مع إمكانية تعليم الأيام).
- **المتصدرون / الآراء / الشروحات المجانية / عن المنصة / ملفات المسابقة**.
- **نوافذ منبثقة**: تسجيل دخول المشتركين، تحديث هام، تقييم، اسم المتصدرين، إبلاغ عن سؤال، قسم غير مشمول بالاشتراك، اكتشاف دخول آخر، تحميل مراجعة PDF، اختبار السرعة V3، البحث الشامل.

## التشغيل

موقع ثابت بدون أي خطوة بناء — افتح `index.html` مباشرة أو:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
# ثم افتح http://localhost:8080
```

## البنية

```
index.html      الصفحة الرئيسية
css/style.css   التنسيقات
js/data.js      المحتوى (الاختبارات، الأقسام، الآراء، بنك الأسئلة…)
js/app.js       السلوك (الكاروسيل، محرك الاختبار، النوافذ، الخريطة، البحث)
```

> ملاحظة: هذه واجهة تجريبية (Frontend) تعكس شكل المنصة الأصلية ومحتواها العام؛ تسجيل الدخول والاشتراكات والتحميلات معروضة للتجربة فقط دون اتصال بخادم.
