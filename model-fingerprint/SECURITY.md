## 🔍 التفاصيل والإصلاحات

### SEC‑2 · تلف أو تلاعب التخزين المحلي (أخطرها)
`localStorage` **مُدخَل لا موثوق** — يستطيع المستخدم أو أي سكربت على النطاق تعديله.
الكود كان يثق في شكله:

```js
// ❌ قبل: يثق في أي JSON يُحلَّل بنجاح
const d = JSON.parse(localStorage.getItem(KEY));
if (d && d.subjects && Object.keys(d.subjects).length) return d;
const S = () => DB.subjects[DB.current];      // قد يُعيد undefined → انهيار
```

**الإصلاح:** دالة `sanitize()` تُعيد بناء الحالة من الصفر بأنواع مضمونة:
- `subjects` كائن عادي فقط (لا مصفوفة ولا `null`)
- كل مساعد يُضمن له `responses` و `overrides` ككائنين
- قيم الردود تُقصر على نصوص/أرقام فقط
- **قيم `overrides` تُقبل فقط من قائمة بيضاء** `["yes","part","no"]`
- `current` المعلّق يُعاد ضبطه لأول مساعد موجود
- `S()` لا تُعيد `undefined` أبدًا

> **المبدأ:** قائمة بيضاء لا سوداء، وإعادة بناء لا ترقيع.

### SEC‑7 · ابتلاع الأخطاء — الأخطر فعليًا
`try/catch` حول التحميل كان يلتقط **خطأ برمجيًا** (ثوابت مُستخدَمة قبل تعريفها — TDZ)
ويُعيد حالة فارغة، فيبدو للمستخدم أن **كل عمله ضاع** بلا أي رسالة.

```js
// ✅ بعد: نفرّق بين «تخزين تالف» و«عطل في كودنا»
catch(e){ console.warn("[mfp] تعذّر تحميل الحالة المحفوظة:", e.message); return FRESH(); }
```

> **درس:** `catch` الصامت يحوّل العطل إلى **فقدان بيانات صامت** — وهو أسوأ من الانهيار الصريح.

### SEC‑1 · الحقن
الردود الملصوقة وأسماء المساعدين تمرّ في `innerHTML`. التهريب كان يغطي `& < >` فقط.
**الإصلاح:** توسيعه ليشمل `" ' / \``  — ويمنع كسر السمات (attribute injection) لا الوسوم فقط.

### SEC‑4 · اسم ملف التصدير
`fingerprint-${DB.current}.md` كان يسمح بـ `../../../etc/passwd`.
**الإصلاح:** `safeName()` تستبدل فواصل المسارات والمحارف المحجوزة ومحارف التحكم، وتمنع `..`، وتحدّ الطول.

### SEC‑3 / SEC‑6 · نجحت من البداية
- **امتلاء `localStorage`** (وضع التصفّح الخاص): الحفظ محاط بـ `try/catch` ويُنبّه مرة واحدة ويستمر العمل.
- **ReDoS:** مدخل ١٢٠ ألف محرف متكرر عبر كل المصحّحات → أقل من ٢.٥ ثانية. و JSON بنصف مليون محرف لا يُسقط المصحّح.

## ⚠️ حدود هذه المراجعة
- الأداة **تعمل كليًا في المتصفح** بلا خادم ولا شبكة؛ لا يوجد سطح هجوم خلفي ولا بيانات اعتماد.
- البيانات تبقى في `localStorage` على جهاز المستخدم — **لا ترسل شيئًا لأي طرف**.
- لم تُراجَع بيئة الاستضافة (رؤوس HTTP، CSP، نطاق التقديم) — يُنصح بإضافة
  `Content-Security-Policy: default-src 'self'` عند النشر على خادم عام.
- هذه مراجعة لكود **هذه الأداة فقط**، ولا علاقة لها بأي منصة أخرى.
